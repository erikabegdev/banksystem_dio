# 🏦 Sistema Bancário em Python

Projeto desenvolvido durante o bootcamp da **DIO**, na disciplina **Sintaxe Básica com Python**.

O objetivo do projeto é aplicar os fundamentos da linguagem Python na construção de um sistema bancário simples, simulando operações essenciais de uma conta bancária.

## 📌 Sobre o Projeto

O sistema permite realizar operações básicas como:

- 💰 Depósito
- 💸 Saque
- 📄 Consulta de extrato
- 🚪 Encerramento do sistema

Durante o desenvolvimento, foram utilizados conceitos fundamentais de programação em Python, como:

- Variáveis
- Estruturas condicionais
- Estruturas de repetição
- Operadores
- Entrada e saída de dados
- Controle de fluxo
- Manipulação de valores

## 🛠️ Tecnologias Utilizadas

- 🐍 Python
- 🔧 Git

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de **praticar lógica de programação e os fundamentos da sintaxe Python**, transformando conceitos aprendidos em uma aplicação funcional.

Além disso, o desafio contribuiu para o desenvolvimento da capacidade de criar soluções simples, organizadas e eficientes utilizando programação.

## 📚 Conceitos Praticados

Este projeto faz parte da minha jornada de aprendizado em Python e representa uma aplicação prática dos conceitos estudados na disciplina **Sintaxe Básica com Python**.
